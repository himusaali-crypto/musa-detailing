APEX AUTO DETAILING — PORTFOLIO DEMO

This is a static HTML/CSS/JavaScript website.

Files:
- index.html
- style.css
- script.js

Deploy:
1. Open Netlify.
2. Drag the entire `apex-auto-detailing` folder into the deploy area.
3. Netlify will publish it.
4. Replace the demo WhatsApp number in index.html with the client's public business number when making a real client version.

The site uses remote Unsplash images, so an internet connection is needed for the photos/fonts.
